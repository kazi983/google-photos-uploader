# Privacy Policy

This is a personal, single-user script that watches a local folder on the
author's own computer for new screenshots and uploads them to the author's
own Google Photos library using the Google Photos Library API
(`photoslibrary.appendonly` scope).

## What data is accessed

- Local screenshot image files (`.png`) on the author's computer.
- The author's own Google Photos library, to which the script appends the
  uploaded images.

## What data is NOT collected

This script does not collect, store, transmit, or share any data with the
author, any third party, or any service other than Google's own Photos
Library API. There is no analytics, logging to an external server, or
tracking of any kind.

## Who uses this app

This application is used only by its author, for personal use. It is not
distributed, and no other users' data is processed.
